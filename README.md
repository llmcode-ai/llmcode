# LLMcode

**opencode, built into VS Code.** LLMcode runs the [opencode](https://opencode.ai) engine under the hood and exposes it in three ways:

- **Native chat model provider** — LLMcode registers as a VS Code language-model provider (`vendor: llmcode`). VS Code's own chat surfaces (Copilot Chat, inline chat, terminal chat) can select **"LLMcode (opencode)"** as the model, so responses are generated by opencode — not by Copilot.
- **Chat panel** — a dedicated editor panel (opens on the right) with a session picker, model picker, reasoning toggle, copy/edit on messages, and streaming responses.
- **Code assistant** — tab autocomplete (ghost text), inline edit of a selection (`Ctrl+K`), and selection commands (`/explain`, `/fix`, `/refactor`, `/test`, `/doc`).

Everything is managed from one **Settings** panel: providers & models, agents, skills, MCP servers, plugins, and general options — plus one-click **import from machine**.

The extension uses only native VS Code APIs: `vscode.l10n` for localization, VS Code color themes, `ThemeIcon`, `QuickPick`, `createTerminal`, `vscode.diff`, and the `lm` language-model API.

## How it uses opencode

LLMcode talks to a managed `opencode serve` process through the official `@opencode-ai/sdk`. On activation it finds the `opencode` CLI, starts the engine, and (if the CLI is missing) offers to install it. Secrets for providers stay in your opencode config.

## Verifying that LLMcode (not Copilot) is answering

1. Open the chat view (Copilot Chat or `LLMcode: Open Chat`).
2. Open the **model picker** in the chat input.
3. Pick any model under **LLMcode (opencode)**.
4. Ask a question — the response is streamed from the opencode engine.

You can also confirm programmatically: `lm.selectChatModels({ vendor: 'llmcode' })` returns the opencode model list (see the test suite).

## Requirements

- VS Code `^1.94.0`
- opencode CLI (the extension offers to install it if missing)

## Commands

- `LLMcode: Open Chat`
- `LLMcode: New Session`
- `LLMcode: Open Settings`
- `LLMcode: Import Skills/MCP/Plugins from Machine`
- `LLMcode: Inline Edit Selection` (`Ctrl+K`)
- `LLMcode: Explain / Fix / Refactor Selection`
- `LLMcode: Toggle Autocomplete`
- `LLMcode: Open Terminal Session`

## Development

```bash
npm install
npm run compile        # esbuild bundle
npm run watch
npm run typecheck
npm test               # runs the extension host test suite
npm run package        # vsce package (.vsix)
```

Press `F5` to launch an Extension Development Host.
